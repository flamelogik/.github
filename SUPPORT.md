# Getting Help

- **Questions about using a tool:** post in [Discussions → Q&A](https://github.com/orgs/flamelogik/discussions).
- **Something is broken:** open an issue in that tool's repo using the bug report form. Include your Flame version and OS.
- **An idea for a new tool:** start in [Discussions → Ideas](https://github.com/orgs/flamelogik/discussions). When it's ready, write it up as a [repo proposal](PROPOSING_A_REPO.md).
- **General Flame questions:** the [Logik forum](https://forum.logik.tv/) and [Discord](https://discord.com/invite/y9ZQFZY2BA) are the best place.

Everyone here is a volunteer. Clear, detailed questions get the fastest answers.
